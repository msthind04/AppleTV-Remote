# Apple TV 遥控器 — Android

[English](README.md)

一个开源的 **Apple TV 安卓遥控器**。原生使用 Kotlin 实现 Apple 的 Companion
Link 协议 —— 不需要 companion 服务器、不需要 Python 桥接、也不需要树莓派，
手机上装一个 APK 即可。

支持现代 Apple TV（老式 DMAP 遥控应用已无法工作的型号也能用）。

> 本项目非 Apple 官方出品。"Apple"、"Apple TV"、"AirPlay"、"Siri" 均为
> Apple Inc. 的商标，此处仅用于说明兼容性。

## 功能

- **自动发现** — 自动搜索同一网络下的 Apple TV
- **Siri Remote 式触摸板** — 外圈为方向键，中央为触摸面。滑动按真实触摸事件
  流上报，并带指针加速度曲线，惯性滚动手感与实体遥控器一致；轻点确认，
  按住触摸面 = 长按（呼出 tvOS 右键菜单）
- **返回、主屏幕、播放/暂停** — 播放键图标跟随真实播放状态
- **电源键** — 轻点打开控制中心（与实体遥控器行为一致）；长按唤醒休眠的电视
- **App 抽屉** — 从 App Store 拉取 tvOS 应用图标的网格，点按直接启动；
  Apple 自家应用的图标内置打包
- **文字输入** — 电视聚焦输入框时手机键盘自动弹出，可直接打字；锁屏通知也
  提供同样的输入入口
- **正在播放** — 标题、艺人、封面、播放进度卡片，可拖动跳转、±10 秒快进快退
- **媒体通知** — 通知栏与锁屏同款控制，无需解锁手机即可操作

## 更新内容

- D-pad 与触摸板合并为一块 Siri Remote 式板面：外圈方向键 + 中央触摸面，
  整面均可滑动，不再依赖起手位置
- 自适应布局：触摸板占据剩余空间；横屏时整屏显示 App 页
- 启动提速：上次连接的设备立即显示；若只有一个配对设备则自动直连
- 唤醒并重连：连接失败（电视休眠）时一键唤醒再连
- 简化「正在播放」卡片（±10 秒；播放/暂停固定在底部按键行）
- 音量长按连调、按键触觉反馈、OK 键收起键盘面板
- 新增中文界面与浅色主题
- 修复偶发的启动闪退

## 安装

从 [Releases](../../releases) 下载最新 APK 安装（需允许安装未知来源应用）。

需要 **Android 8.0（API 26）** 或更高版本，且与 Apple TV 在同一 Wi-Fi 网络。

## 配对

1. 打开应用，点按你的 Apple TV。
2. 输入电视上显示的 4 位配对码。**配对码有效期很短** —— 如果配对卡住，
   取消后重新获取新码再试。
3. 如需「正在播放」功能，按提示进行第二次独立的 AirPlay 配对。

配对凭据使用 Android Keystore 中的密钥加密保存。它拥有 Apple TV 的完整
控制权，请像对待密码一样妥善保管。

## 兼容性

已在 **Apple TV 4K（AppleTV14,1，tvOS 26.6）** 上完整验证。Companion Link
协议自 tvOS 13 起保持稳定，其余型号和版本预计可用但未逐一测试。
