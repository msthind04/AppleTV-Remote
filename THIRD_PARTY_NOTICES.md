## pyatv

Source: https://github.com/postlund/pyatv

This project's protocol implementation is derived from pyatv, a Python
library for controlling Apple TV devices. Specifically, the following
were taken from or verified against pyatv:

- Companion Link frame type values and OPACK type tags
- HomeKit pairing HKDF salt and info strings, and ChaCha20 nonce labels
- Media Remote Protocol message type and field numbers
- RTI (text input) NSKeyedArchiver payload structure
- AirPlay 2 remote-control channel setup sequence and key-derivation salts
- The test vectors in `protocol/src/test/resources/`, which were
  generated by executing pyatv (see `tools/generate_vectors.py` and
  `tools/generate_plist_vectors.py`)
